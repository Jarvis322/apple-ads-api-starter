# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, private keys, access tokens, organization IDs, or account data.

If private reporting is unavailable, open a minimal public issue asking the maintainer to enable a private contact channel. Do not include sensitive technical details in that issue.

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Deployment warning

This repository is a starter, not a production access-control layer. Before internet deployment, add user authentication, authorization, TLS, CSRF protection, rate limiting, secure headers, centralized secret management, and audit logging.
